# Monster-Assets

20 einzeln mit dem integrierten Bildgenerator erzeugte PNGs, transparenter Hintergrund. Bewegung und Trefferreaktion: CSS/JS im Event-Overlay.

Dateien: `web/static/monsters/`. Galerie: `gallery.html`. Übersicht: `preview.jpg`.
